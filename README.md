### Selected Work

#### [Vietnamese Sign Language Recognition](https://github.com/thanhbinh55/VietnameseSignLanguageRecognition) · *Team Lead*
> End-to-end keypoint preprocessing and isolated word-level VSL recognition pipeline.
> - Proposed neck-anchor normalization, increasing SPOTER test accuracy from 78.59% to 84.08% (+5.49%).
> - Preprocessing pipeline enhanced SL-GCN accuracy from 67.44% to 75.41% (+7.97%) through a 14-run ablation study on VSL400.
> - Standardized and released benchmark keypoint dataset with 1,051 clips across 994 glosses from 5 signers.
>
> `Python` `PyTorch` `MediaPipe` `SPOTER` `SL-GCN` `NumPy`

---

#### [Malware Classification from Binary Images](https://github.com/thanhbinh55/Malware_Classification)
> Multi-view static malware classification on the Microsoft BIG 2015 dataset.
> - Engineered feature pipelines combining `.bytes` visual representations, `.asm` opcode n-grams, and statistical descriptors across 5 iterative versions.
> - Achieved Private Leaderboard Log Loss of `0.01153` on Kaggle with cleaned ensemble model.
>
> `Python` `scikit-learn` `OpenCV` `NumPy` `Pandas`

---

#### [Handwritten to Data (RUKOPYS HTR)](https://github.com/thanhbinh55/Handwritten_To_Data)
> Two-stage Ukrainian handwritten text recognition and document understanding pipeline for Kaggle RUKOPYS.
> - Integrated YOLO layout region detection, reading-order geometric sorting, and crop text recognition powered by fine-tuned Qwen3-VL LoRA.
> - Engineered conservative postprocessing to eliminate duplicate bounding boxes and token repetition loops, achieving a Leaderboard Score of `0.66754`.
>
> `Python` `PyTorch` `YOLO` `Qwen-VL` `LoRA` `OCR` `Transformers`

---

#### [LAN Remote Desktop Application](https://github.com/thanhbinh55/Computer_Network_Remote_Desktop_Application)

> - Designed custom bidirectional JSON-over-WebSocket protocol with screen and webcam streaming.
> - Implemented OS-level subsystem controls: Process Manager (querying CPU/RAM, process termination), App Manager, and chunked binary file explorer.

> `C++` `Node.js` `WebSocket` `Win32 API` `Linux POSIX`
